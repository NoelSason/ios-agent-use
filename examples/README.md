# Examples

`lectra/` is a real configuration for a shipping iPad app: a folder-driven Xcode
project with its own `xcodebuild` wrapper, a launch-argument fixture system, and
dot-namespaced accessibility identifiers.

`new-notebook.json` is the shape a useful batch takes — assert the starting
state, act, wait for the destination, act again, assert the result. Seven steps
for the price of one test-runner launch.
